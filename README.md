# 낙엽 쓸기 — 경비원 아저씨의 가을

한예종 경비원 아저씨의 미담에서 영감을 받은 모바일 세로형 도트 게임입니다. 서버 없이 HTML 파일 하나(`index.html`)로 동작합니다.

- **낙엽 모으기**: 조이스틱으로 걸으며 보도블록 위의 예쁜 낙엽 10종을 쓸어서 모으고, 도감 카드로 나무 이야기를 봅니다.
- **낙엽으로 예술하기**: 120자 이내의 문장을 쓰면 아저씨가 낙엽을 쓸어 글자를 완성합니다. 작품을 보관하고 공유할 수 있습니다.

모바일 브라우저의 세로 화면에 맞춰져 있고, 데이터(이름, 모은 낙엽, 작품)는 사용하는 브라우저에만 저장됩니다.
